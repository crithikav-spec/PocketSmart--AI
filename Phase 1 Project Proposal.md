# Phase 1: Project Proposal

## Project Title
PocketSmartAI: Your Smart Budget & Recommendation Assistant

## Problem Statement
Managing budgets across multi-domain needs (home decor, event planning, and apparel/jewelry shopping) is tedious and scattered across different platforms, making cost optimization difficult.

## Proposed Solution
A GenAI-powered web application using FastAPI and Gemini 1.5 Flash Pro that aggregates user budgets, preferences, and image inputs to generate structured, cross-platform product and service recommendations (Amazon, Flipkart, IKEA, Zomato, Swiggy, OYO).

## Core Scenarios
1. Home Interior Budget Planning (room dimensions, lighting, furniture allocation).
2. Party Budget Planning (guest count, catering, venue, and vendor splitting).
3. Jewelry & Outfit Matching (uploading outfit images for aesthetic color-coordinated suggestions).
